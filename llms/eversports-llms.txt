# Eversports

> Eversports is a European sports and fitness booking platform (studios, gyms, clubs) whose Eversports Manager back office exposes two public GraphQL APIs: a read-only Provider API for activity schedules and an Aggregator API for venue/session discovery and reservations. Both authenticate with a Bearer token issued by Eversports.

## APIs

- [Provider API (GraphQL)](https://provider-api.eversportsmanager.io/api/graphql): Read-only access to activity schedules — classes, trainings, workshops, courses, events, retreats, camps, educations — with venue, teacher, room, sport and availability detail.
- [Aggregator API (GraphQL)](https://aggregator.eversports.io/v1/graphql): Venues, classes, sessions and reservations, plus mutations to make/cancel/check-in reservations. Test host: https://aggregator-test.eversports.io/v1/graphql
